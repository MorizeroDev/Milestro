# Rich text showcases / 富文本展示

The XML files in this directory demonstrate Milestro Markup and are shared by
both manuals. Select **Milestro Rich Text** (`milestro_rich_text`) to render them.

本目录的 XML 展示 Milestro Markup，两种手册共用同一份素材。
请选择 **Milestro Rich Text**（`milestro_rich_text`）解析器。

| File / 文件 | Writing mode / 书写模式 |
| --- | --- |
| [Horizontal / 横排](horizontal-example.xml) | `HorizontalTb` |
| [Japanese vertical / 日文竖排](vertical-rl-ja-example.xml) | `VerticalRl` |
| [Traditional Chinese vertical / 繁体中文竖排](vertical-rl-zh-Hant-example.xml) | `VerticalRl` |

For setup, demonstrated markup, geometry queries, and rendering notes, see:

运行方式、展示标记、几何查询及渲染注意事项见：

- [English instructions](../en/examples/README.md)
- [简体中文说明](../zh/examples/README.md)
